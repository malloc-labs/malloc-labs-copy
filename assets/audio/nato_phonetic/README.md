# NATO Phonetic Anchors

Audio files containing the spoken NATO phonetic anchor for each symbol the learner can encounter. See [docs/philosophy.md](../../../docs/philosophy.md) §3.2 and [docs/specification.md](../../../docs/specification.md) §2.6.

Required for v0:

- `Kilo.wav`
- `Mike.wav`

Recordings will be made by an experienced radio operator. Placeholder audio is used during development; placeholders are replaced before any release outside dogfooding.
